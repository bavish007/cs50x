# Week 1 C

## 🎯 Overview

This week marks the transition from visual programming in Scratch to text-based programming in **C**. We dive into the syntax and structure of C, exploring how to write, compile, and execute code using the command line.

**Key Learning Outcomes:**

* **Transition to C:** Moving from blocks to text, understanding syntax, compilation with `make`, and the relationship between source code and machine code.
* **Core Constructs:** Mastering fundamental programming building blocks in C including variables, types (`int`, `char`, `float`, `string`), conditionals (`if`, `else`), and loops (`while`, `for`, `do-while`).
* **Clean Code & Communities:** Learning to use Visual Studio Code and the terminal, while emphasizing the importance of writing well-designed, readable code with comments and proper style.

## 🛠️ Problem Sets & Labs

This week's problem set challenges you to apply your new C skills to solve practical problems:

* **Hello (me):** A simple program to greet the user, ensuring your environment is set up correctly.
* **Mario (Less/More):** Recreating the pyramids from Super Mario Bros. using loops in C. The "Less" version builds one pyramid, while the "More" version builds two adjacent ones.
* **Cash (Greedy Algorithms):** Calculating the minimum number of coins needed to make change.
* **Credit (Luhn’s Algorithm):** Validating credit card numbers and identifying the card issuer using checksums.
