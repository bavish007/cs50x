# Week 0 Scratch

## 🎯 Overview

In Week 0, I explored the fundamentals of computer science and the art of problem-solving. I learned that computer science is not just about writing code, but about thinking algorithmically to solve complex problems efficiently.

**Key Learning Outcomes:**

* **Data Representation:** I discovered how computers use binary (0s and 1s) to represent numbers, text (ASCII/Unicode), images (RGB), and media.
* **Algorithmic Thinking:** I learned to use pseudocode to outline logic before coding, focusing on correctness and efficiency (Big-O notation).
* **Programming Fundamentals:** I applied core concepts like functions, loops, conditionals, and variables using Scratch, a visual programming language.
