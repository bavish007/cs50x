# Week 3 Algorithms

## 🎯 Overview

This week delves into the core of computer science: **Algorithms**. The focus shifts from simply writing code that works to writing code that is *efficient*. I explored how to measure the performance of programs using **Big O notation**, understanding the difference between $O(n)$, $O(n^2)$, and $O(\log n)$. Key concepts include:

1. **Algorithms & Efficiency**: analyzing running time and worst-case scenarios ($O$) versus best-case scenarios ($\Omega$).
2. **Search Algorithms**: Implementing **Linear Search** (checking element by element) and **Binary Search** (dividing and conquering sorted data).
3. **Sorting & Recursion**: mastering sorting techniques like **Bubble Sort**, **Selection Sort**, and **Merge Sort**, and understanding **recursion** (functions calling themselves).
