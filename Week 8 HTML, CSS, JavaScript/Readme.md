## 🎯 Overview

> This week explores the fundamental building blocks of the web, moving from the backend logic of C and Python to the frontend technologies that power user interfaces.

* **The Internet & Networking:** Explored the underlying infrastructure of the web, including how the internet works, routers, TCP/IP, DNS, DHCP, and the HTTP/HTTPS protocols.
* **HTML & CSS:** Learned to structure web pages using HyperText Markup Language (HTML) and style them for visual appeal and responsiveness using Cascading Style Sheets (CSS) and frameworks like Bootstrap.
* **JavaScript:** Introduced to client-side scripting to add interactivity, manipulate the DOM, and handle events directly within the browser.
