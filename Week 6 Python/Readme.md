# Python

## 🎯 Overview

This week marks the transition from C to **Python**, a higher-level, interpreted programming language. The focus shifts from manual memory management and explicit typing to utilizing Python's simplicity and powerful standard libraries.

**Key Learning Outcomes:**

1. **Transition to Python:** Understanding the syntax differences between C and Python (indentation, no semicolons, implicit typing).
2. **High-Level Abstractions:** Leveraging built-in data structures like lists, dictionaries, and sets to solve problems more efficiently.
3. **Libraries & Modules:** Importing and using external libraries (including the CS50 library) to simplify complex tasks like image processing and speech recognition.

## 🛠️ Problem Sets & Labs

This week's problem sets focus on re-implementing previous C programs in Python (Sentimental) and solving a new DNA profiling challenge.

* **Sentimental:**
  * **Hello:** Re-implementing the simple "Hello, World" program.
  * **Mario (Less/More):** Re-creating the Mario pyramids using Python loops.
  * **Cash/Credit:** Re-solving the greedy algorithm or credit card validation.
  * **Readability:** Computing the Coleman-Liau index in Python.
* **DNA:** Implement a program that identifies a person based on their DNA sequences using STR counts.
