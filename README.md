  🎓 ABOUT THIS REPOSITORY
</h2>

**CS50x** — Harvard University's Introduction to Computer Science — is widely regarded as the world's most transformative entry-point into the discipline. Under the direction of Professor David J. Malan, the course does not simply teach students to write code; it fundamentally rewires how they think, reason, and solve problems. Malan's pedagogical philosophy holds that the highest goal of a computer science education is not fluency in any single language, but the cultivation of a **computational mindset** — the ability to decompose complexity, recognize patterns, and engineer elegant solutions from first principles.

This repository is a complete, battle-tested archive of that intellectual journey: twelve weeks of problem sets, labs, and projects spanning visual programming, systems-level C, data structures, databases, full-stack web development, and artificial intelligence. Every line of code here represents not just a completed assignment, but a concept deeply understood and a skill deliberately forged.

It stands as a testament to the belief that, as Malan himself teaches, *anyone* — regardless of background — can learn to think like a computer scientist.

**Octane Vault** is the CS50x Final Project — a high-performance automotive asset management platform and "Garage Operating System" built for collectors and enthusiasts. It transforms a fragmented spreadsheet workflow into a unified, AI-powered investment portfolio. By integrating **Google Gemini AI** for automatic vehicle data synthesis and the **Wikipedia API** for high-resolution imagery, it delivers a premium experience backed by a fully normalized **SQLite** relational data model — all wrapped in a stunning **Glassmorphism UI** with GPU-accelerated CSS animations.

**Key Features:**

- 🤖 **AI-Powered Auto-Fill** — Google Gemini synthesizes engine specs and performance metrics from a vehicle model name alone
- 🖼️ **Wikipedia API Imagery** — Fetches high-resolution vehicle images automatically, zero manual uploads required
- ⚡ **Smart Fallback System** — Localized mock datasets ensure 100% uptime even when external APIs timeout
- 📊 **Portfolio Analytics & Real-Time Equity Tracking** — Aggregate financial dashboard calculates total investment value across the entire garage
- 🏆 **Dynamic User Rank System** — `inject_user_status()` context processor promotes users from Rookie → VIP → Magnate based on garage valuation
- 🎨 **Cyberpunk Glassmorphism UI** — `backdrop-filter: blur(15px)`, "Phantom Drift" and "Laser Scan" CSS `@keyframes` at 60fps
- 🗄️ **Normalized Relational Data Model** — Dedicated services table enables cumulative maintenance cost summation per vehicle
